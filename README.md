# Loja Veloz - Infraestrutura Cloud DevOps

Projeto prático de modernização de infraestrutura, incluindo conteinerização, orquestração e CI/CD.

## Como rodar o ambiente local

1. Certifique-se de ter o Docker instalado.
2. Na raiz do projeto, execute o comando:
   docker-compose up -d

## Tecnologias Utilizadas
* Docker e Docker Compose
* Kubernetes (Manifestos de Deployment, Service, HPA, ConfigMap e Secrets)
* Terraform (Infraestrutura como Código)
* GitHub Actions (Pipeline de CI/CD)
